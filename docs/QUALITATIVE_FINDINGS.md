# Qualitative observations and intentionally challenging images

Several photographs were selected as *a priori* stress cases. Distinguish **planned challenge** from **observed model behavior**; the pilot did not perform controlled image ablations and cannot attribute all errors to a particular cue.

## False specimen splitting

In the location condition, Claude Haiku 5.5 described two fictitious snakes in **img_006** and **img_012**. Per the post-run adjudication instruction, each received 0 points without a fabricated-name penalty. The error is better described as **false object segmentation / body-part splitting** than as invention of a scientific name.

## Persistent difficulty

The image-only condition included **seven** images missed at species level by all models: 004 (*Vipera kaznakovi*), 006 (*Bungarus flaviceps baluensis*), 013 (*Naja samarensis*), 017 (*Acanthophis rugosus*), 019 (*Malayopython timoriensis*), 023 (*Candoia paulsoni paulsoni*), and 029 (*Protobothrops flavoviridis*). Three of these (006, 019, 029) were missed at genus level by everyone. With location, some of those apparent failures were rescued, but **img_017 remained wrong at species level for all seven models**.
