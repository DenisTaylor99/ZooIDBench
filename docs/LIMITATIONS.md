# Limitations and threats to validity

1. **Selection bias:** 30 curated photographs, not a probability sample; model differences may hinge on which species, photographers, environments, and image quality happened to be included.
2. **Small sample and no repeated trials:** seven models × 30 items per condition, with one output per model/item/condition. No confidence intervals or cross-seed reliability estimates have been established.
3. **Chat-context carryover:** images in a condition were processed sequentially within a single conversation, allowing preceding turns to affect subsequent ones despite explicit instructions against using previous guesses.
4. **Memory contamination in excluded attempts:** source panels exposed cross-chat references in preliminary GPT-6.1 Sol and GPT-6 Astra runs. Those runs were discarded from main scoring. The repeated runs showed no sign of retrieval from earlier conversations, but this cannot be verified independently: the interface may not display every source a model draws on.
5. **Prompt compliance not guaranteed:** prohibiting tools or Memory in plain text does not itself guarantee the model/environment avoided every external source. To reduce the chance of contamination, Memory and web search were disabled wherever the interface allowed it. The Gemini app does not allow web search to be disabled: the image-only Gemini run there showed no searches, and two location attempts in which the model did search were discarded.
6. **Different product environments:** testing in consumer apps was deliberate, to measure what users actually receive, but browser/mobile Work and the other consumer interfaces have differing image pipelines, sampling defaults, potentially changing model builds and undisclosed system messages. This is not a strictly controlled API benchmark, and results may not hold for the same models accessed in other ways or at other times. In particular, Gemini 3.5 Flash-Lite's two conditions were run in different interfaces (the Gemini app and Google AI Studio), so its paired comparison cannot separate the effect of the location from the effect of the interface.
7. **Taxonomic uncertainty and historical names:** accepted synonyms and former broader species concepts require adjudication. Some species/subspecies treatments may change. The reference policy and exceptions affect leaderboard totals.
8. **Ground-truth uncertainty:** photo IDs were supported by observer records and expert identifications in the curator's registry, but this release does not claim independent DNA/morphological specimen verification or independent reinspection of every image.
9. **Location granularity:** counties, municipalities, and regions differ in size/information content; some locality labels may almost uniquely imply a taxon. The experiment measures *addition of these particular localities*, not a fixed amount of geographic information.
10. **Post-run manual policies:** special cases and some synonym decisions were settled through review, after the answers were known (though with model identities hidden). Every such decision is listed in the adjudication CSVs, `DECISION_LOG.md` and `data/ORIGINAL_TAXONOMY_NOTES.md`, and both conditions have a fully scored 210-row CSV.
11. **Confidence isn't calibrated probability:** High-confidence precision can be 100% for small selective subsets, and reporting only confident responses obscures failures or abstention.
12. **Safety:** visual-only species identification can be wrong. Benchmark predictions must not be used to decide whether an encountered snake is safe to handle.
13. **Publication, licensing and leakage:** revealing answers and precise source observation links on GitHub allows future models or agents to retrieve them; later benchmark versions should use a new held-out test set and separate public/private answer keys. Photos have individual CC licenses with attribution and possible noncommercial/share-alike restrictions.
14. **No causal claim:** paired gains are consistent with useful location context, but absence of randomized locality counterfactuals or stateless repeated trials prevents attributing all gains solely to geography.

The pilot is intended to identify methodological weaknesses and generate hypotheses for larger follow-up studies, whether in consumer apps with repeated runs or, where affordable, through APIs.
