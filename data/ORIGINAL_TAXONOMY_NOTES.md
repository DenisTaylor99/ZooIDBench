- _Boiga dendrophila_ is a former name for _Boiga melanota_, as _B. melanota_ was previously treated as a subspecies of _B. dendrophila_. An answer with "_Boiga dendrophila_" should be awarded 2 points.

- _Azemiops kharini_ is no longer considered a valid species; it is now included in _A. feae_. Answering _A. kharini_ should therefore be awarded 2 points.

- _Protobothrops flavoviridis flavoviridis_ and _P. f. tinkhami_ are listed by The Reptile Database, which also notes that _P. f. tinkhami_ is not recognized by Gumprecht et al. (2004). Without _P. f. tinkhami_, the species has no subspecies to distinguish, so the correct answer is _Protobothrops flavoviridis_. An answer naming a subspecies is not penalized and receives 2 points.

- _Thelotornis capensis_ currently has no recognized subspecies. If a model ever mentions a subspecies, that shouldn't count as a penalty and should be awarded 2 points.
